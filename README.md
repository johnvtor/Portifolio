# 👨‍💻 João Vitor | Portfólio Pessoal

Bem-vindo ao meu portfólio! Este projeto foi desenvolvido para apresentar um pouco sobre mim, minha formação, minhas habilidades e alguns projetos que venho desenvolvendo durante minha jornada na área de tecnologia.

## 🚀 Sobre o projeto

O portfólio apresenta meu perfil acadêmico e profissional, minhas tecnologias de estudo e alguns projetos relacionados ao desenvolvimento de sistemas.

Atualmente, sou estudante de Engenharia da Computação pela UNIVESP e do curso técnico em Análise e Desenvolvimento de Sistemas pela ETEC Praia Grande.

Tenho experiência com suporte técnico, manutenção de computadores e redes básicas. Também estou desenvolvendo meus conhecimentos em programação e desenvolvimento web.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da página.
- **CSS3:** estilização e personalização visual.
- **Bootstrap 5:** layout responsivo e componentes.
- **JavaScript:** funcionalidades do carrossel e menu.
- **Devicon:** ícones das tecnologias.

## 📌 Estrutura do portfólio

O site está dividido em algumas seções principais:

- **Início:** carrossel de imagens.
- **Perfil:** apresentação pessoal, formação e áreas de interesse.
- **Tecnologias:** ferramentas e linguagens que estou estudando.
- **Projetos:** apresentação de trabalhos e atividades.
- **Contato:** links para e-mail, GitHub e LinkedIn.

## 💻 Projetos apresentados

O portfólio apresenta três projetos:

1. **Portfólio Pessoal:** página para apresentar meu perfil e meus conhecimentos.
2. **Sistema em Python:** aplicação com foco em lógica de programação e processamento de informações.
3. **Landing Page Responsiva:** página desenvolvida com HTML, CSS e Bootstrap.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em seu navegador.

**Observação:** o Bootstrap e o Devicon são carregados por CDN, então é necessário ter conexão com a internet para utilizar esses recursos.
